## 为什么

前端功能已较完整(会话管理、知识库、调试侧栏、技能弹窗、工作动态时间线),但对比 ChatGPT、Claude、Perplexity 等成熟 AI 对话产品的界面实践,在美观与易用性上仍有明显差距:

- 仅有浅色主题,无暗色模式与主题切换(`App.css` 中无任何 dark 令牌)。
- 缺少业界标准的消息级操作:助手消息无复制/重新生成/反馈,用户消息无编辑回填,消息无时间信息。
- 重命名/删除会话依赖浏览器原生 `window.prompt`/`window.confirm`,与应用内已具备的精致对话框(如飞书导入、知识中心)风格割裂。
- 新会话空状态只有一句英文默认回复,缺少能力引导与建议提示词(ChatGPT/Claude 均以建议卡片作为首屏)。
- 工具调用气泡状态写死为 "running",从不反映真实完成/失败;请求失败只能读一段错误文本,没有重试入口。
- 存在少量硬编码实体文案(头部徽标 "12306"、按 "train/ticket/station" 关键词匹配图标),违反仓库 AGENTS.md 泛化性约束。
- 视觉质感整体偏平面:圆角层级不统一,除基础过渡外缺少入场/浮层等动效,也没有毛玻璃等现代材质,与当前主流 AI 产品的"胶囊输入区 + 柔和大圆角 + 分层动效 + 玻璃顶栏"语言存在差距。

## 变更内容

- 建立完整主题体系:在既有设计令牌基础上扩展暗色令牌集,提供浅色/暗色/跟随系统三档切换并持久化,首屏加防闪烁初始化;补充 favicon 与运行状态页面标题;代码块增加语法高亮与一键复制;新增全局轻量 toast 反馈。
- 强化视觉质感:统一放大的圆角体系(消息气泡、胶囊形输入区、卡片与对话框);建立分层动效体系(消息与动态入场、对话框/浮层过渡、toast 滑入、悬停微交互、流式工作脉冲指示,全部尊重系统"减弱动态效果"偏好);为顶栏、输入区与模态遮罩等固定表面引入毛玻璃材质并带能力降级。
- 增强消息级交互:助手消息提供复制/重新生成/点赞点踩,用户消息提供编辑回填;消息显示相对时间;工具气泡显示真实运行状态;错误消息提供重试按钮;聊天区新增"回到底部"浮标。
- 改进会话管理易用性:重命名与删除改用应用内对话框;会话列表增加搜索过滤、时间分组与相对时间;抽取通用对话框原语供各处复用。
- 新增会话空状态引导:展示通用能力说明卡片与建议提示词(配置驱动、不含具体实体示例),点击回填输入框。
- 泛化界面硬编码:头部徽标仅保留通用能力并动态展示已安装技能;工具图标映射改为通用类别判断。

## 能力

### 新增能力

- `frontend-visual-system`:双主题体系,圆角、动效与毛玻璃材质,视觉细节打磨(代码高亮、favicon、toast、文案语言一致性)与界面硬编码实体清理。
- `chat-message-interactions`:消息级操作(复制、重新生成、编辑回填、反馈)、消息时间、工具调用真实状态与错误重试。
- `session-management-usability`:应用内会话重命名/删除对话框、会话搜索、时间分组与相对时间显示。
- `welcome-empty-state`:新会话空状态引导与通用建议提示词卡片。

### 已修改能力

无。

## 影响

- 前端:`frontend/src/App.jsx`(组件抽取与交互逻辑)、`frontend/src/App.css`(暗色令牌、新组件样式、硬编码颜色令牌化)、`frontend/index.html`(favicon、主题初始化脚本)。
- 新增依赖:`rehype-highlight`(代码高亮,携带 highlight.js 主题样式);圆角、动效与毛玻璃均为纯 CSS(含 `@supports` 能力降级)实现,不新增运行时依赖;不引入 UI 组件库,沿用现有 React + lucide-react 技术栈。
- 后端:可选新增最小 `POST /feedback` 端点接收消息反馈;端点未就绪时前端反馈操作降级为仅本地记录,不阻塞本变更。
- 测试:更新 `frontend/src/App.*.test.jsx`,为主题切换、消息操作、会话对话框、空状态新增组件测试。
- 不改变 SSE 事件契约、会话存储结构与知识库 API。
